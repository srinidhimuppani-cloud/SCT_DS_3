# SCT_DS_3 - Bank Marketing Decision Tree Classifier

This project was completed as part of Task 03 during the *Data Science Internship at SkillCraft Technology*.

## 📌 Project Overview
The objective of this task is to build a *Decision Tree Classifier* to predict whether a customer will subscribe to a term deposit based on demographic and marketing campaign features from the UCI Bank Marketing dataset.

## 📊 Model Performance & Findings
* *Model Accuracy:* ~90%
* *Key Insights:* 
  * *Call Duration (duration):* The primary split factor determining subscription probability.
  * *Previous Outcome (poutcome_success):* Past successful marketing engagements strongly correlate with new subscriptions.

## 🛠️ Tech Stack
* *Language:* Python
* *Libraries:* Pandas, Scikit-learn, Matplotlib, Seaborn
* *Environment:* VS Code
